# SkillVerdict

## Editing content

All text content is stored in `lib/strings.ts`. This file contains all the text
content used throughout the application. It's organized by sections to make it
easy for editors to find and modify content.

## Navigation data

The navigation data is stored in `lib/navigationData.ts`. This file contains all
the navigation data used throughout the application. It's organized by sections
to make it easy for editors to find and modify content. Modifying the order in
the navigation data will change the order of the sections on the page.
